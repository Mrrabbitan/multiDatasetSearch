# POC 指标口径说明

## 标注指标
- **自动标注准确率**：抽样金标准对比的正确检测比例（置信度≥0.9）
- **低置信度占比**：置信度低于阈值（如0.9）的样本比例
- **标注速度**：单机 GPU 的平均吞吐（帧/秒或张/秒）
- **人工审核时长**：单样本平均修正耗时

## 检索指标
- **检索延迟**：向量检索 + 结构化过滤的端到端响应时间
- **混合检索命中率**：向量/关键词融合后 TopK 命中比例（抽样）

## 训练指标
- **mAP@0.5**：IoU=0.5 的平均精度
- **mAP@0.5:0.95**：IoU 0.5~0.95 的平均精度
- **训练收敛**：达到稳定指标所需 epoch 数
